# Contributing

Please keep fetched catalog data, editorial classifications, and recommendations separate.

When proposing a recommendation:

1. Link the Pi package page and upstream repository.
2. Record the collection date.
3. Explain the primary use case and overlap with existing packages.
4. Check the package README, release activity, compatibility, and security implications.
5. Do not equate npm downloads with unique users or quality.

Changes to the generated snapshot should include the source URL and collection date.
